The Dream Decoder

for fun · not psychology · not even slightly
This is not psychology and it is not therapy. There are two readers in here and the page always says which one answered. The first is a language model, told in as many words that it is not a psychic, not a therapist and not a dream dictionary: what it does instead is read the dream as a piece of night-time writing — what it is built out of, how it is put together, and the exact point where it stopped bothering to be consistent. It never says what anything “means” about you, because nothing in a dream does. That reading is sent to the generator and is not stored. The second is the old jumble-sale dream book, invented for this cabinet, which takes over if there is no key on the server and which you can ask for on purpose; it runs entirely in your browser. If a dream is genuinely bothering you, a person is better than a web page, and this web page in particular. ← back to the cabinet
