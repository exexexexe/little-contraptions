How this works

The live marker is the station's reported position. The track and the pass times are computed here in your browser by propagating the current orbital elements with SGP4 — the same model the elements are published for.

A pass counts as visible only where the station is in sunlight while your sky is dark, both at once, for at least a minute. Most passes fail that test and are listed anyway, marked as not visible.

Position from wheretheiss.at, with Open Notify as a fallback — proxied through this server because Open Notify has no HTTPS endpoint and a browser will not load it from a secure page.
