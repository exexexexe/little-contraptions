The Paradox Machine

put one in · get a worse one out
Two machines live in here and the page always tells you which one answered. The first is a language model on the server, asked to take your statement seriously: where it forks, where it turns on itself, what older problems it is related to, and whether it is a paradox at all — because most things typed into this are not, and saying so is the more interesting answer. The second is the original clause machine, assembled from lists written for this cabinet, which takes over when there is no key on the server or the model will not answer, and which you can ask for on purpose with “machine only”. Nothing is quoted from any philosopher. What you type goes to the generator when the first machine is in use and is not stored anywhere. ← back to the cabinet
