Country names, capitals and currencies come from the open mledoze/countries dataset (ODbL), the same one the REST Countries API is built from — that API now needs a signed-up key, so the data is baked in here instead and nothing on this page phones home for it. Flags are served by flagcdn.com. Only the 193 UN member states are asked about, which keeps the awkward questions about what counts as a country out of a quiz that has no business settling them. Wrong answers are drawn from the same part of the world as the right one, so a lucky guess has to be an informed one. ← back to the cabinet
